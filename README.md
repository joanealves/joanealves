## Projetos

### 🌱 [AgroIA](https://agroiatecnologia.com.br)
Plataforma SaaS de gestão agropecuária — arquitetura e desenvolvimento integral.

- **Back-end:** Django · Django REST Framework · PostgreSQL · Celery · Redis · WebSockets · JWT
- **Front-end:** Next.js 15 · React 19 · TypeScript · Tailwind · Zod — entregue como **PWA offline-first** (fila em IndexedDB e sincronização CRDT para uso em campo sem conexão)
- **IA e ML:** Claude e OpenAI no copiloto do produto · XGBoost para previsão de safra · Whisper para registro por voz · OCR · ONNX Runtime no navegador
- **Geoprocessamento:** Sentinel-1/2 · indexação hexagonal H3 · Leaflet e MapLibre GL · exportação de shapefile para agricultura de precisão
- **Billing:** Stripe e Mercado Pago com cobrança recorrente, webhooks e gating de planos

### 🧠 [Schema](https://schema.dev.br)
Ecossistema de produtos digitais construídos sobre uma arquitetura comum, o Schema Core:
plataforma de conhecimento com IA que responde citando a fonte, analisador de contratos e
de editais, gerador de relatórios e extração de dados de PDF.
